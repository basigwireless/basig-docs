## What You'll Learn

<div class="bw-talks bw-modules" markdown>

- **Understanding 5G Architecture**
    - Overview of the 5G Standalone (SA) architecture
    - 5G New Radio RAN protocol stack (PHY, MAC, RLC, PDCP, SDAP)
    - Core network components: AMF, SMF, UPF, NRF, AUSF, NSSF, UDR, UDM, BSF, PCF

- **Hands-on: End-to-End 5G Connection Setup**
    - Configure and activate 5G Core modules, gNB and UE, and connect a 5G phone
    - Measure signal strength, bandwidth usage and coverage
    - UE registration, de-registration, service request and PDU session establishment
    - Latency and throughput analysis; authentication and call-flow analysis using PCAP files
    - 5G protocols: GTP, NAS, HTTP/2, PFCP and NGAP

- **Hands-on: 5G-Enabled IoT Applications**
    - Connect an IoT bridge and IoT devices to the 5G network
    - Use cases: weather monitoring, livestock tracking, irrigation control, electric vehicle control and navigation

- **Demonstration: Network Slicing**
    - Set up network slicing using multiple virtual machines
    - Switch UEs between user planes (UPFs) for different speed and bandwidth per slice

- **Demonstration: Multi-Access Edge Computing (MEC)**
    - Object detection using machine learning
    - Distribute processing loads across edge worker nodes

- **Demonstration: 5G Service-Based Architecture**
    - Explore real-world API interactions with REST-based 5G services
